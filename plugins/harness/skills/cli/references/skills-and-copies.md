# Skills and copies that write

These commands change files, each backed up first, always under `<root>/repo-sync-backups/<stamp>/`. They run for real unless `--dry-run` is given.

| Command | Returns (`--json`) |
| --- | --- |
| `consolidate retire --name <n> --kind skill\|agent --from <global\|repo dir>` | `{kind, name, from, path, backup, identicalTo, applied}`; a Global copy is retired only when an identical plugin copy exists |
| `skills move --leaf <skill>/<path> --to <skill>[/<path>] [--market <dir>]` | `{op, changes: [{action, file, detail}], backup, applied}`; moves a file or folder of a skill into another skill, repoints every mention of its path in the skills, agents and market plugins, backs every changed file up first; an identical file at the destination only drops the source, a different one stops with exit 1; `check` rows name text that still mentions the old place. Both skills are looked up under `<root>/skills` and, with `--market`, in its plugins; a name in two places stops with exit 1 and lists them, and `<plugin>:<skill>` (in `--leaf` or `--to`) picks a plugin's copy. Moved into a plugin's skill, an absolute mention (`~/.claude/skills/<from>/<path>`, `$HOME/...`, `%USERPROFILE%\...`) becomes `<this skill>/<path>` inside the target skill and `<skill>/<path>` elsewhere |
| `skills split --from <skill> --name <new> --leaves a,b [--description <t>] [--market <dir>]` | the same shape: creates the new skill under `<root>/skills` (a SKILL.md with one row per leaf) and moves the leaves into it; `--from` is looked up as in `skills move` |
| `skills put --file <file> --to <skill>/<path>\|agents/<name>.md [--market <dir>]` | the same shape: puts new or rewritten text in place, an existing file backed up first; the skill is looked up as in `skills move` (`<plugin>:<skill>/<path>` picks a plugin's) |
| `skills remove --name <skill>\|--leaf <skill>/<path> [--repo <dir>] [--market <dir>]` | the same shape: deletes a skill, one leaf, or a stray folder with no SKILL.md (from `hunt catalog`'s `strays`), backed up first, and lists what still mentions it; `--repo` takes it from `<dir>/.claude/skills` and also checks the repo's CLAUDE.md, rules, skills and agents; without it the skill is looked up as in `skills move` |
| `skills repoint --from <skill> --to <skill> [--skills a,b] [--agents x,y] [--market <dir>]` | the same shape: rewrites the mentions of one skill name to another; the skill's own folder, every plugin folder of `--market` that ships it (or ships the `--to` skill) and `<root>/skills/synced` stay as they are. To a plain name (no plugin prefix) only reference forms change: `` `name` ``, `<plugin>:name`, `skills/name`, `name/references/...`, `name/scripts/...`, a relative link target into the skill (`](../name/...)`) and "name skill"; a mention beside the word agent, on a `subagent_type` line or as `agents/name.md` stays, and when an agent of that name exists so do a bare `` `name` `` and `<plugin>:name` unless "skill" follows; every line that still names it is a `check` row (`line N still names it: ...`); exit 1 when nothing is rewritten |
| `skills fix-paths --market <dir> [--plugin <p>] [--dry-run]` | the same shape with `op: 'fix-paths'`: in every skill of the market's plugins (or of `--plugin`), an absolute path to a global skill folder (`~/.claude/skills/<name>/`, `$HOME/...`, `%USERPROFILE%\...`, `C:\Users\<u>\.claude\skills\<name>\`, a bare `.claude/skills/<name>/`) becomes `<this skill>` for the skill's own folder and `<plugin:skill>` for a skill exactly one plugin of the market ships; a skill that still exists under `<root>/skills` keeps its path; Markdown only, each file backed up first; every other path (a skill found nowhere or in two plugins, any path in a script) is a `check` row `line N, <why>: <text>`; exit 2 without `--market`, 1 for an unknown `--plugin` |
| `skills rename --from <skill>\|<plugin>:<skill> --to <name> [--market <dir>]` | the same shape with `op: 'rename'`: renames the skill's folder (looked up as in `skills move`) and its `name:` line, then rewrites the reference forms as `repoint` to a plain name does, the skill's own files included, and lists every other mention as `check` rows; every changed file backed up first; exit 1 when the skill is missing, in two places, or `<to>` exists beside it |
| `sync apply [--repo <dir>] [--name <n>] [--dry-run]` | `{copies: [{repo, kind, name, state, files, backup, error?}], applied}`; syncs the repo copies that differ from Global, backed up under `<root>/repo-sync-backups/<stamp>/`; exit 1 for an unknown `--name` or a failed copy |
| `sources update --name <skill> [--dry-run]` | `{name, source, from, to, changed, added, removed, backup, applied}`; installs the source's version into `~/.claude/skills`, backed up under `<root>/repo-sync-backups/<stamp>/skills/<name>` first |
| `check fix [--repo <dir>] [--dry-run]` | `{repos: [{repo, fixable, changes: [string], backup, error}], applied}`; applies the settings and hooks fixes, the repo's settings and hooks backed up under `<root>/repo-sync-backups/<stamp>/<repo path>/` first; exit 1 when a repo errored |
| `sessions rename --session latest\|previous\|<id> --title <t> [--repo <dir>] [--dry-run]` | `{session, file, from, to, applied}`; renames as /rename does; a running session gets its own name back at exit |
